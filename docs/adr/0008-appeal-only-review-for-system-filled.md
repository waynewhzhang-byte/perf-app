# 0008 — 系统填充维度只审申诉，无异议直通归档

**Status:** accepted (2026-07-23)  
**Relates to:** ADR-0005（部分收窄）、ADR-0002

对系统填充 / 事实导入维度：人类审核对象仅为员工**申诉**；员工申报级**确认无异议**（无申诉）时跳过 L1 逐项与 L2 逐选项待办，直接走归档快照写入 `PerformanceRecord`。有申诉时，非申诉项亦不进入 L1/L2 待办。

原因：业务要把审核产能集中在异议上，且申报表已改为只读核对 + 底部统一申诉；若仍为每条无异议评分点生成 ADR-0005 式 L2 待办，会与「申诉行工作台」模型冲突。代价是无申诉路径下导入错误只能靠事后事实修正暴露，须由导入质量责任兜底。

ADR-0005 对**仍存在的手工填写维度**是否继续适用，不在本决策范围内。
