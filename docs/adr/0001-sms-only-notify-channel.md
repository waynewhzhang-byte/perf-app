# 0001 — SMS 为唯一通知渠道，EMAIL 仅作代码预留

**Status:** accepted (2026-06-13)

生产环境选择阿里云 SMS 作为唯一通知渠道；`NotifyConfig` 设计成可切换 SMS/EMAIL 的全局单例，
但 EMAIL（SMTP）实现保留仅为代码灵活性，不投入运维。原因：员工均有公司手机号，
短信覆盖率与触达及时性优于邮件；运维一套 SMTP（含反垃圾、收件箱丢失排查）成本不划算。

后续若要启用 EMAIL，需重新评估已注册员工的联系方式类型兼容性
（`User.contact` 列既可能是手机号也可能是邮箱，切换渠道会让已注册账号失效）。
