# 0004 — 模板发布后内容完全不可变

**Status:** accepted (2026-06-13); amended (2026-07-27)

`FormTemplate.status` 一旦从 `DRAFT` 转为 `PUBLISHED`，禁止修改任何表单内容：
结构（章节、申报项、分值档次、maxScore、dimensionCode）、分值，以及标题/说明/提示等文字。
不再提供「文字修订」通道。

允许的操作仅限：

- 预览
- 复制为草稿（在新草稿上改，再发布替换）
- 归档（`PUBLISHED → ARCHIVED`）
- 二级子项分配（审核路由元数据，不改表单内容）

原因：生产环境模板发布后员工已可见并可申报；任何内容改动都会造成进行中申报与模板不一致。
纠错与结构调整统一走「复制为草稿 → 编辑 → 发布」工作流。

**显式 no-scope**：表单设计器的"可视化拖拽"在已发布模板上是禁止操作，不在产品路线图上。
