# 0006 — 预审为软提示，不阻断提交

**Status:** accepted (2026-06-13)

`AutoReviewRule`（工龄区间 × 申报等级的合法组合）在提交时运行，但**不通过不阻断提交**——
只返回 `preReviewWarnings` 在前端展示并附在通知里。是否申报由员工自己决定，由 L1/L2 审核兜底。

原因：入职时间（`hireDate`）来自 HR 导入数据，历史上有不准确的情况；强阻断会把合法申报
挡在门外，员工无法自助纠正数据错误。软提示让人工审核成为最终防线，与"事实由审核员核对"
的整体设计一致。

**显式 no-scope**：不会引入"硬预审 + 管理员豁免"的双轨制——一旦硬阻断，豁免流程的运维成本
会超过收益。
