### Step 4 — `POST /api/admin/users` 拆分（P1，已有 discriminatedUnion 基础）

把单个 280 行函数按 `action` 拆成 4 个私有 handler，顶层 `POST` 只做 dispatch。文件已有 `BodySchema = z.discriminatedUnion('action', [...])`，正好按它分发：

```ts
export async function POST(req: Request) {
  const session = await requireAdmin();
  if (session instanceof NextResponse) return session;

  const parsed = BodySchema.safeParse(await req.json());
  if (!parsed.success) return NextResponse.json({ error: '参数无效' }, { status: 400 });

  const authCfg = await getAuthConfig();
  const enforceStrong = usesStrongPassword(authCfg);

  switch (parsed.data.action) {
    case 'create':      return handleCreateUser(parsed.data, enforceStrong);
    case 'update':      return handleUpdateUser(parsed.data);
    case 'setPassword': return handleSetPassword(parsed.data, enforceStrong);
    default:            return handleRoleMutation(parsed.data); // 'add' | 'remove'
  }
}
```

每个 `handleXxx` 搬迁原有 if 分支的**全部逻辑**（含其内部 try/catch、Prisma 错误映射），顶层保留单个外层 `try/catch` → 500。错误码、状态码、校验顺序逐字保留。无单元测试覆盖此路由，所以拆分后**逐分支对照原文件 diff 自检**，并在 `pnpm build` 验证类型。
